# Product Vision

## Overview

Lithos Mind is a public-data-first personal knowledge base agent project. It is built around public-safe personal data to support learning, reading, cultural collection management, and the understanding of long-term interests.

## Long-Term Vision

The long-term vision is to:

- Build a personal knowledge base agent that can help the owner organize, retrieve, and understand long-term public learning and interest data.
- Support source-aware answers.
- Transform scattered public notes and records into a structured and searchable knowledge system.
- Evolve in stages instead of attempting to complete every capability at once.

These capabilities describe the intended direction of the project and are not implemented in the current phase.

## Target User

Lithos Mind is designed for:

- The project owner.
- A personal learning and knowledge management user.
- Someone who wants to manage public-safe personal knowledge assets over time.

It is not intended for enterprise use, team collaboration, or operation as a commercial SaaS product.

## Core Product Idea

The core product idea is based on:

- Public-safe personal data as the knowledge base.
- Structured data preparation before agent capabilities.
- Retrieval with source traceability.
- Agent answers grounded in the user's public-safe knowledge records.
- A simple interface and public demo in future stages.

These ideas define future product direction rather than completed functionality.

## Why Public Personal Data

Using public-safe personal data:

- Reduces privacy risk.
- Makes the project easier to review and demonstrate.
- Keeps the scope focused.
- Fits a portfolio-oriented AI product management project.
- Allows future public deployment without exposing sensitive information.

## AI PM Portfolio Value

Lithos Mind is intended to demonstrate the following AI product management capabilities:

- Product positioning.
- Scope control.
- Data boundary definition.
- Agent product thinking.
- Stage-based roadmap planning.
- Collaboration with engineering tools such as Codex.
- Turning a vague AI idea into a structured, reviewable, and buildable project.

## Current Stage Boundary

Lithos Mind is currently in the **Project Initialization Phase**.

This phase focuses on:

- Repository setup.
- Basic documentation.
- Data policy planning.
- Sample data format planning.
- Environment configuration.

This phase does not include:

- Agent implementation.
- Retrieval-augmented generation (RAG).
- Embeddings.
- A vector database.
- A frontend.
- Deployment.
- Real data ingestion.

## Evolution Principle

The project will evolve through reviewed stages:

- Start with clear boundaries.
- Build minimal deliverables.
- Review each stage before expanding scope.
- Avoid over-engineering.
- Keep GitHub milestones stable and presentable.
